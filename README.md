# IceBel Contracts Web — Генератор розничных договоров купли-продажи

Веб-приложение для автоматизированного оформления розничных договоров купли-продажи климатического и сопутствующего оборудования компании **ООО «АйсикБел»** (icebel.by). Сервис заполняет официальный шаблон Word (`.docx`), ведёт журнал договоров в SQLite и может автоматически загружать готовые документы на Google Drive.

Система оптимизирована как для работы на компьютере, так и со смартфонов/планшетов, а также подготовлена к мгновенному бессерверному деплою на **Vercel** (Serverless Functions + Edge CDN).

---

## Основные возможности

- **Удобная форма оформления договора (Desktop + Mobile)**:
  - Быстрый ввод ФИО покупателя, телефона (с автоформатом `+375`) и адреса доставки в Республике Беларусь.
  - Быстрые подсказки в один клик: типовые адреса (Минск, квартира, дом) и популярные товары (+ Daikin Emura, + Cooper&Hunter, + Wi-Fi модуль, + Монтаж).
  - Спецификация оборудования: динамическое добавление/удаление строк, настройка количества, цены в BYN и срока гарантии (12, 24, 36, 60, 84 мес. или свой срок).
  - На смартфонах таблица адаптируется в карточки оборудования с крупными элементами управления, удобными для пальцев.
  - Плавающий нижний мобильный бар с актуальной суммой и кнопкой моментального скачивания договора.
- **Мгновенный расчёт (0 ms)**:
  - Автоматический подсчёт сумм по каждой позиции и итоговой стоимости заказа.
  - Сумма прописью на русском языке с корректными падежами для белорусских рублей и копеек (BYN).
  - Автоматическая генерация инициалов покупателя для стандартизированного названия файла.
- **Генерация официального Word-документа**:
  - Точное заполнение утверждённого шаблона `templates/retail_contract_template.docx`.
  - Динамическая вставка строк в таблицу товаров с сохранением фирменного форматирования, границ и шрифтов.
  - Заполнение реквизитов сторон (ООО «АйсикБел» и Покупатель).
- **Интеграция с Google Drive**:
  - Опциональная автоматическая загрузка сформированного документа в заданную папку на Google Диске через Service Account или OAuth.
- **Журнал и поиск договоров**:
  - История всех сохранённых договоров с датами, суммами и перечнем товаров.
  - Живой поиск по фамилии покупателя, номеру договора или телефону.
  - Повторное скачивание документа или открытие ссылки в Google Drive прямо из журнала.

## Быстрый запуск на компьютере

1. Откройте терминал в папке проекта `icebel_contract_web`:
   ```bash
   cd C:\Users\naru4\OneDrive\Desktop\icebel_contract_web
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   - Дважды кликните по файлу `start_local.bat`
   - Или выполните в консоли:
     ```bash
     python run_local.py
     ```

4. Откройте в браузере: **`http://127.0.0.1:8000`**

---

## Деплой на Vercel

1. Загрузите проект в репозиторий GitHub.
2. В панели [Vercel](https://vercel.com) выберите **«Add New...» → «Project»** и импортируйте репозиторий.
3. В разделе **Environment Variables** при необходимости укажите:
   * `GOOGLE_DRIVE_FOLDER_ID` — ID целевой папки на Google Диске;
   * `GOOGLE_SERVICE_ACCOUNT_JSON` — содержимое JSON-ключа сервисного аккаунта Google (в одну строку).
4. Нажмите **Deploy**. Проект сразу готов к работе.

```
│   │   ├── dates.py       # Форматирование дат договоров

│   └── index.py           # FastAPI сервер и REST API
├── public/
│   ├── index.html         # Адаптивный веб-интерфейс
│   ├── styles.css         # Стили и мобильная адаптация (Vanilla CSS)
│   ├── app.js             # Логика клиента (форма, расчёт, журнал, мобильный бар)
│   └── logo.jpg           # Фирменный логотип IceBel.by
├── templates/
│   └── retail_contract_template.docx # Шаблон договора с метками
├── vercel.json            # Конфигурация для деплоя на Vercel
├── requirements.txt       # Зависимости Python
├── run_local.py           # Точка запуска локального сервера
├── start_local.bat        # Быстрый запуск для Windows

```
